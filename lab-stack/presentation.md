# Le Projet Technique

- **Nom du projet** : Plateforme web de gestion d'articles (blog)
- **Rôle principal** : créer, publier, organiser et consulter des articles en ligne
- **Ce qu'on développe** : une application complète avec interface et base de données
- **Les acteurs clés** : l'**administrateur** gère tout le site, le **rédacteur** écrit ses textes
- **Structure des données** : 3 tables reliées (**Rédacteur**, **Catégorie**, **Article**)

# La Stack Technique

- **1. Langages** :
  - **HTML5** (structure) & **CSS3** (style visuel)
  - **JavaScript** (interactions front-end) & **PHP 8** (logique serveur)
- **2. Frameworks & Bibliothèques** :
  - **Laravel** : framework PHP pour le traitement serveur
  - **React** : bibliothèque JavaScript pour créer des interfaces utilisateur
  - **Tailwind CSS** : framework utilitaire pour styliser rapidement
  - **Alpine.js** : bibliothèque pour des interactions réactives simples
- **3. Base de données & ORM** : **MySQL** (stockage sécurisé) et **Eloquent ORM** (relations)
- **4. Outils** : **VS Code** (éditeur), **Git** (versioning), **Marp** (présentations)

# Comprendre les Labs

- **Qu'est-ce qu'un lab ?** : un **atelier pratique guidé** pour apprendre une compétence en sécurité
- **Pourquoi réaliser des labs ? (Les 4 piliers)** :
  - **1. Découvrir** : explorer un nouvel outil ou une nouvelle syntaxe
  - **2. Pratiquer** : manipuler le code pas à pas avec des exercices simples
  - **3. Tester** : valider une solution technique avant son intégration
  - **4. Apprendre de ses erreurs** : corriger les bugs pour progresser sereinement
- **Lien avec le projet** : chaque lab valide une **brique essentielle** du site final
- **Exemple concret** : tester le formulaire d'article dans un lab avant de le relier à MySQL et Laravel
