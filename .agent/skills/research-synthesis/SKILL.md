# Research Synthesis

## Principes
1. Preuves d'abord : documentation primaire, données vérifiables, recoupement de plusieurs sources.
2. Équilibre : compromis, alternatives et avis contraires.
3. Lisibilité : titres, listes, matrices de comparaison.
4. Incertitude explicite : distinguer faits vérifiés, hypothèses et questions ouvertes.

## Workflow
1. **Cadrer** : question précise, public, profondeur ; découper en sous-questions (faisabilité, coût, performance, sécurité, alternatives) ; choisir les sources faisant autorité.
2. **Proposer** : partager le plan de recherche et confirmer le périmètre avant une investigation lourde.
3. **Collecter et synthétiser** : lire, extraire, recouper ; écarter les affirmations non vérifiées ; citer les sources.
4. **Vérifier** : chiffres et citations fidèles aux sources, recommandations cohérentes avec les preuves, jargon réduit.

## Livrables
- **Brief exécutif** : résumé (2-3 phrases) + métriques clés + tableau de décision.
- **Revue technique** : architecture + comparaison + recommandations d'implémentation.
- **Analyse marché** : paysage + matrice des acteurs + implications.
Structure type : Résumé, Comparaison, Risques et compromis, Recommandations actionnables, Sources.

## Vérification
- [ ] Chaque affirmation clé est sourcée ou marquée comme hypothèse
- [ ] Au moins deux angles/alternatives présentés
- [ ] Recommandations déduites des preuves
